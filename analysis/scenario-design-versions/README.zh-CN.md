# 场景版本登记：v4.0 / v4.1

**后续设计以 v4.1 为基线。** v4.0 是上一版40题（历史内部代号 V4R2）；v4.1 是当前32题（内部代号 V4R3）。早期探索稿 V4R1 不改名为 v4.0。
这两个版本均为设计快照，不能当作已完成实验。已有模型实验仍是原24题。旧ID保留，避免同名 A01 在不同目录中被误认为同一个世界。

## 为什么由40题变为32题

- A/B/G共16题压缩为A/B共8题：A强调摄入过程，B强调既有治疗状态、药效与未完成输注。保留原复杂日程，不按少吃/多餐/给药史重复扩张主题。
- A05/A06的报告高估/低估移出主集：I2隐藏餐食记录后，这一报告关系不可观察，能力覆盖与未知摄入重复。不是宣称两个真实摄入量的生理轨迹相同。
- G01/G02的给药时点进入B01的主世界/匹配对照；G03/G04/G06留诊断档案，不冒充同总量同日程的单因素对照。
- D由2增至6：保留旧两题，新增黎明进入/退出、缺觉退出、慢餐后短时应激、无运动的饮酒延迟扰动。只用现有机制/代理，不新增未经支持的生理方程。
- H由8减至4：正常摄入高需求、低摄入高需求、需求与摄入恢复错位、疾病叠加送达不足。恢复时点变体放到匹配对照，不按病名堆题。
- C/E不变；F保留六题。年龄、性别、硬件、信息档位仍为独立维度，不当作事件类别。

## 信息条件、对照和实施状态

I0/I1/I2是同一物理世界的观测投影，不改真实摄入、送达或状态。I1按场景隐藏部分关键记录；I2隐藏外部进餐、治疗等记录，但仍给出由可见记录计算的IOB/COB，自身动作和回执独立保留。故障导致的CGM中断/偏差归F，不混入记录隐藏维度。新增题的有效I1投影仍需正式审计。
每个主世界都应有独立WAIT基线；机制反事实是额外匹配世界，不能用某个统一WAIT替代所有题。给药时点、恢复顺序等反事实不额外占主主题数，但实际运行时要计入世界/轨迹数量。
目前仅通过schema和初始化检查。未声称新增32题已完成难度验证、完整轨迹审计、信息投影审计或模型实验。原生工具/交互/评分没有在这一步修改。
