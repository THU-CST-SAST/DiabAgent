# 场景 V4：近年证据与当前模型能力核对

日期：2026-10-18。对象是当前 `feature/scenario-metrics-v3` 工作树，不是旧 App 仿真器，也不把先前冻结实验的代码当作当前代码。本文是定向文献核对，不是系统综述；多数研究依据公开摘要，已获取正文的条目另注明。不声称完整审阅所有论文全文。

配套：[场景重设计](scenario-v4-capability-balanced-design-20261018.zh-CN.md)。新增的只是研究设计、离线探针与记录，未修改生理内核、场景生成器、评分或启动付费模型实验。

## 1. 证据如何使用

三个命题必须分开：存在同类现实机制；代码能生成这种工程扰动；代码复现了该机制在人群中的定量响应。前两个成立不推出第三个。新论文的阴性结果也必须保留，不能只找支持“更大干预”的证据。

以下 N 编号是本次补查，不替换已有 R 编号。研究支持场景类别或限制，不是直接提供每题剂量、吸收倍率、敏感性变化幅度或病程长度。

| 编号 | 研究及类型 | 本次核对到的内容 | 对设计的限制 |
|---|---|---|---|
| N01 | [Riddell 等，2023，T1DEXI](https://pubmed.ncbi.nlm.nih.gov/36795053/)，497 名成人，真实生活中随机分配结构化运动类型 | 有氧、间歇、抗阻的平均运动期血糖变化不同，个体离散很大 | 不能把全部无氧/间歇运动写成必然升糖；不能用组均值规定个人曲线或映射 AC |
| N02 | [Al Ozairi 等，2026-07，TREX](https://pubmed.ncbi.nlm.nih.gov/42265980/)，66 人交叉 RCT，晨间进食/空腹、下午进食抗阻运动 | 部分比较的运动后指标不同，较明显差异见 MDI 亚组；不少比较未显著 | 同一“运动名称”不足以描述药效暴露和代谢状态；并不支持所有泵用户同样出现这些差异。公开摘要数值排列有歧义，本文不据此拟合系数 |
| N03 | [Jo Kamimoto 等，2024](https://pubmed.ncbi.nlm.nih.gov/38441232/)，95 名低糖感知受损者与 95 名匹配对照，4236 次运动 | 受损组基础低糖风险较高，但运动与该分组的风险交互未显著 | 不把“低糖无感知”随意变成额外运动降糖倍率。它也不是当前内核的 Z 或 rdepl 状态 |
| N04 | [Garcia-Tirado 等，2023](https://pubmed.ncbi.nlm.nih.gov/37478323/)，35 名成人、三种 AID 模式交叉 RCT；核对公开正文摘要 | 加入进餐预期没有显著改善主要餐后 TIR 结局 | 不保证“猜午餐时间”优于反应式控制；加入迟到/取消的意向对照。该研究没有证明所有预期策略无效 |
| N05 | [Laugesen 等，2024](https://pubmed.ncbi.nlm.nih.gov/38805311/)，189 名 6–21 岁 AID 用户、回顾性队列 | 漏打/迟打与较低 TIR 相关 | 研究对象不是本项目成人参考患者；算法检测与观察关联不能变成通用惩罚系数，也不等于实验中的记录隐藏 |
| N06 | [Li 等，2025](https://pubmed.ncbi.nlm.nih.gov/40507137/)，两个小型急性交叉试验，蛋白来源 n=16、混合餐 GI n=8；核对 PubMed 摘要 | 不同蛋白来源间、以及该高脂高蛋白背景下的两种 GI 餐，没有显著血糖差异 | 不因食物名称不同就固定制造不同曲线；不显著不等于已证明等效，更不能推广到所有餐 |
| N07 | [Hall 等，2024](https://pubmed.ncbi.nlm.nih.gov/38820834/)，34 名成人、12 周 RCT，限制碳水饮食背景 | 额外按蛋白计算给药，相对只按碳水给药，未显著改善 TIR 等主要指标 | 同类机制有意义，但不能设计成“识别蛋白就必须追加”的唯一正确策略；不作为饮食处方 |
| N08 | [Yu 等，2025](https://pubmed.ncbi.nlm.nih.gov/40176254/)，288 名住院 T1D 患者、前瞻性观察；摘要和出版商结论 | 避开脂肪增生部位后的剂量调整随亚型不同 | 支持部位状态与治疗需求变化；不是随机 PK 钳夹试验，不能标定“更换部位后旧药库瞬间释放” |
| N09 | [Li 等，2024，T1DEXI 周期分析](https://pubmed.ncbi.nlm.nih.gov/38972477/)，179 名女性、个体内阶段比较 | 晚黄体期与早卵泡期的平均血糖和需求存在差异 | 仅适用于相关患者配置；不是所有女性都统一增加需求，也不能把性别本身列为一个事件族 |
| N10 | [Mesa 等，2024](https://pubmed.ncbi.nlm.nih.gov/38441905/)，13 名女性、39 对周期，切换 AHCL 前后观察 | AHCL 改善各阶段指标，但阶段差异及给药变化仍存在 | 与 N09 共同支持周期变化候选，不能用商用闭环响应直接标定无闭环 LLM 任务 |
| N11 | [Kong 等，在线 2025、卷期 2026](https://pubmed.ncbi.nlm.nih.gov/40711834/)，连续酮体监测临床研究中的单例 | 导管脱落后血酮上升，监测促使及时处理，病例未住院 | 低等级个案支持研究方向，不证明预防 DKA 的总体疗效；当前无酮体模型，不能作为已有动态评分场景 |
| N12 | [Aiello 等，在线 2023、卷期 2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12035211/)，酮体报警算法的原始建模研究 | 提出利用 BOHB 模型/测量发现输注中断的方法 | 是可进一步核对的模型线索，不是当前 Deichmann2023 已实现的功能，不能直接嫁接一个固定酮体轨迹 |

保留的旧机制依据：已有 [R01–R13](scenario-family-evidence-v1-20261016.zh-CN.md) 覆盖给药时序、条件性应激、缺觉、输注与测量；[原 R14–R22](../sweet-sim/knowledge/scenario-hard-evidence-v3.json) 覆盖慢餐、饮酒及相关局限。关于温度仍以 [2009 局部加温交叉试验](https://pubmed.ncbi.nlm.nih.gov/19539098/) 为具体原始证据，不用新综述冒充新的直接实验。关于计碳仍保留 [2020 计碳误差建模原始研究](https://pubmed.ncbi.nlm.nih.gov/32223551/) 与 [2013 真实餐食观察](https://pubmed.ncbi.nlm.nih.gov/23146371/)。新旧证据按问题选择，不能只按年份排序。

## 2. 代码核对分级

- E：当前有状态/原语，可通过公开配置或动作表达。仅表示工程支持，不是临床验证。
- P：有运行中的代理实现，但疾病/营养/激素等语义比代码更丰富，必须以“合成扰动”标记。
- C：有底层计算的一部分，但缺少事件/API 或必要状态，不能直接用作该语义的题目。
- U：当前没有对应完整状态转移或动作/观测，不能通过改名称假装支持。

```sh
node analysis/audit-scenario-v4-capabilities.mjs
```

## 3. 必须修正的三种语义误用

1. `kind:'anaerobic'` 并不等于已实现抗阻运动生理。正式题目应写清 AC 输入和代理肝糖项，并保留无明显升糖的对应任务。
2. 输注丢失与吸收变慢不是同一种机制。前者药物没有进入身体，后者药物仍在仓库；修复时不能清除/补回任意药量。
3. `information_mode:'complete'` 和 I0 不是同义词。前者会改正部分报告，破坏“信息本身有误”的场景；I0 只能保留记录，不能获得评测方真实参数。

## 4. 暂不纳入现有血糖主评分的研究方向

X01 周期转换与跨日适应：已有代理，可作为符合配置的长时子集；不把所有男性基础试验切成女性，也不将性别当事件族。

X02 酮体与升级处置：需要 BOHB 动力学、测量工具和处置动作；若仍只用当前血糖分数，会漏计风险，不能声称该部分已被评价。

X03 低糖无感知/反调节失败：需要新的生理/症状状态，不靠年龄或既往一次低糖自动生成结论。

X04 真实胃轻瘫、肾/肝功能、药物相互作用：需要额外状态及验证。新资料可为其立项，但不能为了扩充数量用简单缩放替代。

## 5. 本轮核验边界

运行探针是为了确认“当前能表达什么”，不是为了筛出模型失败题、拟合患者历史或测临床效果。没有连接硬件/NS，没有发送治疗数据，没有调用 GLM/GPT。没有覆盖、重新解释或重打包此前冻结的 low/max 实验。
