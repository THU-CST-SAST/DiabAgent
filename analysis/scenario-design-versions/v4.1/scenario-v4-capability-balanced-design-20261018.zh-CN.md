# 场景 V4R3：精简餐食/给药，扩展非疾病扰动

日期：2026-10-18。状态：设计修订及现有接口配置检查，尚未注册为正式 benchmark，未运行新模型实验。评分、提示词、模型、交互和旧题集均不修改。

## 1. 本次收敛

- A05/A06 移出主情景。关键餐食记录完全隐藏后，高估/低估这一报告关系不再可观察，题目退化为真实摄入差异，与已有漏报进餐覆盖重复。这不代表“所有 I1 条件都无意义”或两个不同摄入世界会有相同轨迹，而是本批不再单独测这项报告误差。
- 原 A/B/G 共16题，收敛为 A、B 两类各4题。以主挑战区分：A 的核心是摄入过程怎样变化；B 的核心是已有治疗状态、残余作用和设备未完成承诺。不能要求餐食题没有胰岛素或给药题没有进食，那样不贴近连续控制。
- 同一历史给药的早/晚时点、需求恢复的早/晚条件放入机制对照，不再每种都占一个主主题。对照仍有独立物理世界和轨迹，不能把主情景数当实际运行量。
- D 从2题扩至6题，覆盖非疾病的时钟需求、休息状态、暂时正向肝糖、延迟负向肝糖；H 从8题精简至4题，不另起多个“病种”类别。
- 原24题及实验仍冻结不动，新核心原样使用其中20题。其余原 A01/B04/D01/D02 留在 legacy24 对照集，不是判定无效或删除。选择依据是机制去重，不依据本轮模型谁赢。

## 4. D扩展的具体一天

新 D01/D02 沿用 V4R2 同号，来源是原24题的 D03/D04，完整保留。以下新增配置用当前已存在的参数/事件；不新造内分泌或代谢模型。

| 新题 | 一天安排 | 独立考察点 |
|---|---|---|
| D01 两次短时应激消退后分别接活动 | 原T+0—150/600—720两次应激，T+180/760活动，四餐不变 | 多相位复合反馈 |
| D02 缺觉与黎明叠加后的需求恢复 | 原缺觉至T+1080、黎明项、四餐、T+1220运动不变 | 多因素进入与退出 |
| D03 未进食时的黎明需求进入与退出 | 00:00起，已有黎明函数03:00进入、05—08时较强、10:00退出；11:00/15:30/19:00进食35/55/50g | 没有新餐时需求仍可变化，且不是全天固定 |
| D04 缺觉相关需求退出后仍继续进食 | 06:00—18:00已有缺觉代理，三餐07:30/12:30/18:30为35/55/50g | 需求代理退出但旧药库、后续摄入继续 |
| D05 慢餐后的短时应激及其消退 | 07:30摄入40g、τ150min，08—10时正肝糖代理；14:00/18:00再吃50/45g | 独立正向扰动结束，不等于慢餐和药效都结束 |
| D06 无运动背景下的饮酒延迟肝糖扰动 | 12:00至次日12:00；13:00/18:00/次日07:30三餐，19:00饮酒记录；午夜—08:00负向肝糖代理，之后观察4小时 | 当前看似稳定与后续延迟扰动的区别，避免全是增量需求 |

D03/D04分别使用现有 dawn/sleep_loss，D05/D06分别使用现有 stress/alcohol 代理，依据沿原 R03/R06/R07/R15。系数和小时级时序为合成配置，不是研究拟合或临床处方。不支持的疾病、药物和蛋白机制继续不纳入。

应激空腹无明显效应可作 D05 的辅助反例，但其叙述隐藏后可能与普通物理背景重复，不再单独生成三档全套主情景来凑数。

## 5. H精简而不是换名字拆病种

| 新题 | 采用的V4R2题 | 含义 |
|---|---|---|
| H01 正常进食下持续高需求 | H03 | 与只靠餐食输入解释升糖区分 |
| H02 持续高需求伴摄入减少 | H05 | 保留需求与摄入的相反影响 |
| H03 疾病需求与食欲恢复先后错位 | H06主世界 | 同一摄入日程，需求14:00结束或22:00结束构成先后对照，不再各占主主题 |
| H04 疾病高需求叠加送达不足及修复 | H08 | 保留病日复合压力，不把所有差异归因于一个原因 |

H03 的严格配对保持三餐15/20/50g及时间不变，只改需求恢复时点。旧 H07 还改了餐量、起始时点和加餐，不能直接作为该严格对照。旧早恢复/多次需求等变体在历史目录和 legacy24 中保留，但不继续扩张新核心。H 仍是已有 illness 代理，不声称真实感染的自然病程只需数小时。

## 6. 结果汇总与实施边界

本次旧模型表现只能按原 A–F 统计，原 D 包含旧疾病两题，不能拿新 H 分类回套。[GPT/GLM max 六类三档汇总](max-models-family-information-20261018.zh-CN.md)及 [JSON](max-models-family-information-20261018.json)来自同一份完成版原生报告；144份归档核对 max 请求、同题集/代码/选项、无WAIT补尾。

新核心32与legacy24共享20个物理世界，不能当成56个独立世界；未增加种子和机制对照前，并集为36。主主题数不是实际调用量，配对世界和每世界WAIT仍须另计。不同信息档位共享物理日程，但派生估计及可见记录按原契约计算；自身回执继续保留。

只改设计和分析：28份物理配置深比较保持V4R2原样，另4份D配置通过当前schema/初始化。原 FAMILIES 注册表尚未扩展，新增I1投影及完整轨迹/控制世界审计仍待实施。未启动新LLM、未改评分、未commit/push。
