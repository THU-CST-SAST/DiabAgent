## 1. 当前模型的后续研究到底扩展了什么

当前固定的生理模型是 Deichmann 等 2023 年的 [T1D Exercise Model](https://doi.org/10.1371/journal.pcbi.1010289)，本地上游来源与许可见 `sweet-sim/vendor/deichmann2023/PROVENANCE.md`。

本次执行只读命令：

```sh
git ls-remote https://gitlab.com/csb.ethz/t1d-exercise-model.git HEAD
```

返回 `6bc0a4f6b728a274a51d271a79cb59c24848b19a`，与本地固定提交一致。这只说明查询到的当前默认 HEAD 相同，不排除其他分支、未发表工作或其他团队研究，不能声称“所有模型已经穷尽”。

找到同团队 Zimmermann、Kaltenbach 的 [2025 后续研究](https://doi.org/10.1016/j.ifacsc.2025.100337) 和 [对应 Python 仓库](https://gitlab.com/csb.ethz/t1d-exercise-rl-extended)。论文 2.1 明确继续使用 Deichmann2023 患者仿真器。扩展主要在 MPC+强化学习控制器：输入、奖励、动作和个体适应等，而不是给患者模型增加蛋白、脂肪增生、激素药物或 HAAF 生理。可以借鉴状态历史、运动时序和独立策略比较，但不能引用它宣称六项缺失机制已获实现或验证。

文献中整个仿真框架的状态数与本地 `model/Deichmann2023.ts` 核心状态数不直接等同；后者 14 个状态，外围另有餐食/传感器等适配。不能仅凭数字差异判断移植漏项，应按具体方程与参考用例核对。

## 2. 六项新增候选的核对和处置

| 候选 | 查到的研究线索 | 与当前内核的关系/缺口 | 当前决定 |
|---|---|---|---|
| A06 独立蛋白/脂肪效应 | [2025 UVA/Padova 高脂高蛋白餐扩展](https://doi.org/10.1016/j.ifacol.2025.06.018)；[2026 MI-OMM 餐食成分研究](https://pubmed.ncbi.nlm.nih.gov/42029052/) | 前者属于另一患者模型，作者仍声明缺少无混杂的专门验证；后者以 120 人、353 条餐时轨迹估计胃潴留、出现率和敏感性，不是 Deichmann 扩展，也不能据此实现“低碳高蛋白”的通用动力学。本次未核实可直接复用的完整代码和参数 | 暂缓。不能用额外隐藏碳水或固定 1.2 倍冒充；A04 只保留“慢葡萄糖输入”语义 |
| B07 温度改变吸收 | [局部加温交叉研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3380773/)；[健康人受控加温研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3230259/) | 研究条件和制剂不同；后者虽见灌注增强，却未发现吸收与灌注相关。当前只有静态 PK 参数，尚未找到可直接复现并已验证的同模型温度事件模块 | 暂缓。不能自行指定每升温一度加快多少，也不能改用输注丢失代替 |
| B08 脂肪增生/部位变化 | [Famulla 等 2016 随机交叉研究](https://pubmed.ncbi.nlm.nih.gov/27411698/)；[2025 部位亚型前瞻性研究](https://pubmed.ncbi.nlm.nih.gov/40176254/) | 前者测量了吸收、药效和变异性，后者支持部位相关的需求变化；均不能提供当前内核运行中部位切换、旧新药库分离的完整验证实现 | 暂缓。需要现成可核验的部位 PK 模型及数据，不把未送达药物当体内储药 |
| C06 既往低糖/反调节受损 | [Breton 等 2007 HAAF 动态模型](https://pmc.ncbi.nlm.nih.gov/articles/PMC2709857/)；[2024 运动匹配研究](https://pubmed.ncbi.nlm.nih.gov/38441232/) | 前者有动态方程和独立行为/反调节系统，曾与 85 人资料比较，不是当前内核的小参数；后者也不支持任意增加“运动额外风险倍率”。未核实可直接合并的作者代码 | 暂缓。不能把运动 Z 状态改名当 HAAF；更不能把自带治疗行为反馈的旧模型整体叠加造成双重控制 |
| D06 糖皮质激素等药物 | [2024 胰岛素—葡萄糖—糖皮质激素脉冲模型](https://pmc.ncbi.nlm.nih.gov/articles/PMC11682098/)；已有临床试验可说明现象 | 该数学模型有 I/G/H 方程，主要分析周期解及稳定性，表 1 部分参数标为 Assume。不是当前 Deichmann 的患者级、具体药物剂量与途径验证扩展 | 暂缓。不能把 illness 乘数改名当激素药代，也不能把理论稳定性当临床轨迹验证 |
| F06 指尖污染 | [Hirose 等 2011 实验](https://pubmed.ncbi.nlm.nih.gov/21282342/)和 [2012 后续采样研究](https://www.sciencedirect.com/science/article/abs/pii/S016882271200054X) | 是观测过程，不是生理模型扩展。现有指尖随机误差不含污染、清洗、采样条件和相应工具；临床现象本身不足以给所有仪器规定相同偏差 | 暂缓。未来只能依据可复现的测量研究建观测模块，不能凭空设一个可重复触发的假读数 |

以上“暂缓”不是断言世界上不存在相关模型，而是当前核对尚不足以采用。尤其 A06 的两篇新研究支持继续调查，但没有解决当前内核兼容性；混合餐效应与独立蛋白代谢也不能混为一谈。

### 机制采用标准

顺序应是：确认现象 -> 找到已发表状态转移模型 -> 获得方程、参数、单位和实现 -> 原样复现参考输出 -> 核对与当前状态/输入的兼容性和守恒 -> 独立验证组合后的输出 -> 注册新场景。

本轮不自行发明新的生理机制、系数或状态连接。若只有另一模型体系可用，应先考虑单独模型子集，而不是擅自拼成“Deichmann 扩展版”。没有依据就暂不纳入正式实验，不靠填满 40 个候选的数量推动实现。

已有的 P 类疾病/应激/睡眠等是当前工程代理，不因本次调研就升级成临床验证机制。可继续用于明确标注的合成扰动测试，但不能新增无依据的病理细节或以代理输出证明真实疾病疗效。这个准入标准作用于出题和模型实现，不是新增 Agent 运行门禁。

## 3. 每个场景需要哪些对照

上一版把四个额外任务叫“阴性/维持对照”，容易误导成只有四道题有对照。更准确的名称是“维持/反例校准任务”，它们不能替代以下逐场景比较。

| 比较 | 固定什么 | 改变什么 | 回答的问题 |
|---|---|---|---|
| 同世界策略基线 | 患者、初始历史、事件、设备、世界随机流、时间窗 | Agent vs WAIT；后续可另设固定规则控制器 | 对这一个具体世界，Agent 是否比不追加动作更好 |
| 同世界信息消融 | 所有物理定义、随机流、工具和评分 | I0/I1/I2 的外部记录投影及记录派生估计 | 同一场景中信息缺失的影响 |
| 关键因素配对世界 | 患者、设备、普通生活背景、无关随机流、模拟规则 | 只移除/替换预注册的关键事件或关键时序 | 干预策略是否合理依赖那个因素，而非通用餐时捷径 |
| 维持/反例校准 | 无需额外治疗的背景或意向不兑现 | 例如有/无意向消息，实际摄入保持不发生 | 是否因题名、消息或时间先验而无谓治疗 |

**当前已有逐世界 WAIT，不是本轮才想起来补。** `sweet-sim/src/experiments/scenario-pipeline.mjs::runScenarioPipeline` 中，`withWait` 使用 `agents:['wait']`、`modelDraws:1`，针对已注册世界运行一个信息投影；`paired-campaign.mjs` 的旧 24 世界实验对应 24 条 WAIT。要确认本次具体运行是否包含它，仍需看 campaign 配置及实际任务记录，不能只看默认参数。

WAIT 是“无新增 Agent 操作”，不是“撤掉所有胰岛素”：原有基础输注、起点前药库、已承诺的输注、计划中的外源事件和设备动态按原环境继续。既定历史不能删掉，既定基线也不能换成另一个患者。

WAIT 不读取信息并作决策，所以在固定动作下已确认 I 档位不改变物理环境时，一个物理世界只需一条 WAIT，可用于比较该世界三个 I 条件的 Agent；不必为 I0/I1/I2 再伪造三个独立基线。新增背景种子/患者/硬件则形成新的物理世界，须各自有 WAIT。

配对世界不是把整条曲线固定成相同。Agent 的后续动作不同，真血糖当然可以分叉；同样动作脚本下的信息投影一致性才是必须通过的物理审计。若改变起点前治疗，要重新回放对应历史得到各自生理状态，不能复制一个不符合历史的初态。不同关键事件也可能合理改变初始值，不能为了“像”而人工篡改状态。

## 4. 逐候选的关键因素对照

下列是研究设计，尚未生成额外配对实例。每一行除该配对外，事件世界和配对世界都应各自有 WAIT；两模型在同一世界中比较。共享可比背景种子，不把“相同种子”误当关键因素也相同。

| ID | 事件世界 | 关键因素对照世界 |
|---|---|---|
| A01 | 预打后餐取消/迟到 | 同一预打历史、餐按原计划发生 |
| A02 | 记录高估实际摄入 | 实际摄入不变、估计准确；若既往给药依据记录已发生，须分清纯记录对照与治疗后果对照，不能同时静默改两项 |
| A03 | 低估/漏掉一顿实际摄入记录 | 同一真实摄入完整/准确上报；这是上报机制对照，三档进一步删记录是另一轴 |
| A04 | 相同输入量吸收较慢、已有药效较早 | 相同输入量、普通输入时间常数；不称高脂代谢模型 |
| A05 | 同总量分两段摄入 | 同总量在一段摄入，关键时间差为实验因素 |
| A06 | 独立蛋白/脂肪效应，待模型 | 匹配碳水与其他背景、仅变相应宏营养成分，匹配原则先按所采用研究定义，不随意声称等热量 |
| B01 | 近期纠正仍未充分起效 | 更早给药的 B02 型历史；不强制两条初态完全同值 |
| B02 | 较早给药、残余较少 | B01 型近期纠正，背景一致 |
| B03 | 同一时段多次给药叠加 | 同样总量在预注册较分散时点，或去除重复剂量；两种问题须分别立项，不能一对同时改总量和时序 |
| B04 | 当前高但已有明确下降、药效仍在 | 相近高值但药效/趋势不同的 B01/B02；以回放自然得到的状态为准 |
| B05 | 后续摄入取消、延长输注仍在 | 同样摄入改变但没有剩余输注承诺；或摄入兑现但承诺相同，分别定义对比 |
| B06 | 刚补碳、CGM 尚未回升 | 同样既往药效但尚未补碳；评估残余输入，而不是虚构摄入立即有效 |
| B07 | 温度改变吸收，待模型 | 同模型同制剂正常条件，沿原研究可复现的温度方案 |
| B08 | 异常部位改为正常部位，待模型 | 继续原部位；旧新给药必须按各自部位分仓，禁止恢复未送达药物 |
| C01 | 同一负荷落在药效较强时段 | C02 型较低残余药效；另可配相同历史不运动，分清两个因素 |
| C02 | 同一负荷落在药效较弱时段 | C01 型较强残余；不一边换强度一边换给药史 |
| C03 | 相同总 AC 输入按间歇排列 | 连续排列；总量一致不代表两者生理负荷等价，仅审计输入时序 |
| C04 | 运动后仍有持续作用 | 相同背景未发生该运动；不在运动结束时清零状态制造伪对照 |
| C05 | 未恢复时再次活动 | 总次数/负荷相同但间隔较长；需足够长的共同观察窗，不靠尾部截断 |
| C06 | 既往低糖影响反调节，待模型 | 无该既往低糖历史；按所采用模型分别回放状态，不人工统一 CR 状态 |
| D01 | 需求上升与摄入减少并存 | 同样低摄入但没有需求扰动 |
| D02 | 需求恢复而旧药效仍在 | 相同前期需求与历史、该窗口需求尚未恢复；不重置药库 |
| D03 | 黎明需求变化 | 相同生活背景无该日内扰动 |
| D04 | 缺觉扰动及恢复 | 正常休息背景，无该扰动；不赋予随机睡眠名词固定临床剂量 |
| D05 | 缓慢敏感性漂移 | 相同个体固定敏感性；明确工程统计扰动，不叫完整病理机制 |
| D06 | 特定药物作用，待模型 | 同种药物/研究定义的无用药或停用条件，不能擅自合并不同药物 |
| E01 | 静默送达不足 | 同命令、正常送达 |
| E02 | 间歇送达不足 | 同背景持续正常送达；若研究间歇与持续故障，则另立具体比较 |
| E03 | 已有故障后修复 | 同一故障前史但该窗口尚未修复，已入体药效不变 |
| E04 | 输注故障与传感器异常叠加 | 优先 2×2：二者皆无、仅输注、仅传感器、两者并存，分别有 WAIT |
| F01 | 传感器伪低 | 无偏差；真实低糖另作鉴别配对，不混同因果消融 |
| F02 | 传感器伪高 | 无偏差；真实高糖另作鉴别配对 |
| F03 | CGM 断流 | 相同真实事件、正常观测；不能用 I 删除记录代替物理缺口 |
| F04 | 校准过期导致停更 | 同设备校准有效；设备状态是关键变化，其他硬件不变 |
| F05 | 错误校准后的偏差 | 同设备按合适测量正确校准；注意真实参考测量本身也有误差 |
| F06 | 采样污染，待观测模型 | 同方法无污染/按研究要求清洁，不能在无工具时把“已清洗”记为环境动作 |
| G01 | 进餐背景下应激延迟下降 | 同餐同药效、无该肝糖扰动 |
| G02 | 有应激情境但空腹时未强制升糖 | 同物理过程无应激叙述，是叙述反例；不可据此宣称实现了自主决定的应激生理 |
| G03 | 暂升结束而纠正作用仍在 | 同前史、暂升尚未结束；或无额外纠正的固定脚本，用于机制审计，两个问题分开 |
| G04 | 饮酒延迟负向肝糖代理 | 相同摄入/活动、无该代理扰动；不是乙醇药代验证 |

## 5. 四个额外任务的准确角色

N01 稳定维持：没有新增主要扰动，检查是否凭空改变治疗；必要测量/设备维护仍允许。

N02 已有纠正生效：高值正在按既往作用改善，检查是否机械追加。与 B01/B04 有覆盖，生成目录时可作为它们的稳定对照复用，不必强行另算一题。

N03 进餐意向取消且未预打：实际不进食也无药物承诺，检查是否把意向当事实。与 A01 的区别是 A01 已有胰岛素暴露，取消进餐并不意味着不需要处理。

N04 活动意向取消：未发生实际活动，检查是否按不存在的运动改治疗；意向/取消只能在发生时可见，不提前泄漏未来。

“阴性”不表示一律 WAIT，也不是评分答案；正确策略仍由环境结果衡量。实际目录应允许把这些校准条件挂到对应任务的配对关系，而不是只给全题集加四条就声称完成对照。

## 6. 数量和边界修订

上一版 `34×3+4=106` 只是未包含逐场景机制配对、也未计 WAIT 的事件候选预算示意，不是完整研究规模；现在不应继续用它代表最终实验量。

应先登记去重后的物理世界集合 W（包括事件世界、关键因素配对和必要校准任务），再计算：LLM 轨迹数为各世界有效信息投影数之和 × 模型数 × 模型重复数；WAIT 则每物理世界/环境重复一次。没有可隐藏记录的世界不强行造三份，已在其他地方出现的同一对照不重复计数。复合题可能需更多消融世界，故也不直接写成所有任务机械乘二。

本次仅修订研究设计记录：保留 40 个候选作为目录，六个待模型候选不进入当前正式运行集合；已有原语/代理也须按语义、参数和观测契约审核。未修改模型、评分、实验 runner，未启动 API 调用，未提交或推送。
